4Softer — studio, not gallery

Turn 3 read as deco because of the hard ink borders, square corners and formal serifs. These drop all three: no keylines at all, generous radii, humanist and rounded type, soft mono for the figures, and shadow doing the work that borders were doing. Warm rather than archival, so it sits as comfortably next to a painting app as a code editor. Live as before.

4aSketchbook — warm paper, terracotta

Karla with DM Mono figures. Borders replaced by tone: panels are a shade lighter than the ground, so structure is felt rather than drawn.

4bStudio — soft dark, sage

Warm charcoal instead of black, Sora, sage accent. The neutral ground is honest for judging colour without the clinical feel of a pure dark UI.

4cWash — tinted white, muted violet

Softest of the three: panels barely tinted off the ground, largest radii, Manrope. Almost no edges anywhere.

3Art-book stylisation

Same structure, treated as a printed colour specimen. Serif type throughout, square corners, hairline rules and a heavy ink border instead of a soft shadow, so the window reads as a plate rather than a chrome panel. Each one is mounted in a mat board with a printed caption; the numbers stay monospaced, which in this context reads as an archival specimen label. Still live — tabs and swatches work.

3aAtlas — laid paper, oxide red
PL. I Current colour, with complementary and shade ramp

Newsreader for everything but the figures. The title bar becomes a printed header band; the coral mark cools into oxide red so it sits on aged paper.

3bBistre — dark plates, gilt rule
PL. II The palette library, four of twelve

Spectral on bistre ground with a gilt keyline. Palettes sit like mounted specimens, and every sample is judged against dark neutral rather than paper.

3cGouache — cool board, prussian ink
PL. III Named colours, sampled and catalogued

EB Garamond, a cooler board and prussian accent. The circular chips in the colour library already read as pigment dabs; this treatment leans into that.

2Pick mode — the frozen screen

The cursor keeps the v1.0 feel: crosshair plus a round pixel loupe. What is new is that the loupe carries its own readout, so your eye never leaves the sample point, and a tray at the bottom holds a multi-pick run of five. Move your mouse over the card — the loupe samples live. The desktop behind it is a placeholder; drop in a real screenshot when you have one.

2aLoupe with attached readout · multi-pick tray

11×11 pixel grid at 16×, centre cell ringed. Hex and RGB ride under the loupe on a dark chip so they read against any wallpaper. Crosshair uses difference blending rather than a fixed colour.

1Three aesthetics for the compact window

Same footprint as v1.0 (440 × 640) and the same job order — Pick, Current, Palettes, Colours, Build, Settings — moved from the greyed-out menu bar into a single tab row. All three are live: click the tabs, click any swatch to make it the current colour, switch harmony sets. The differences are surface, type and how loud the colour is allowed to be.

1aPaper — faithful evolution

Keeps the cream ground and coral mark from v1.0. Instrument Sans for labels, IBM Plex Mono for every number, so hex values are always monospaced and column-aligned.

1bGraphite — colour does the talking

Near-black shell so samples are judged against neutral, not against cream. Space Grotesk, wider radii, blush accent lifted from the Winter Sunset palette.

1cGlass — floating utility

Translucent panels, no hard window edge, DM Sans. Reads as an overlay that lives on top of your work rather than an application window.
