# Fonts

Latin subsets of the three families the prototype uses, self-hosted so the app
makes no network request at runtime and renders identically offline.

| File | Family | Weights |
|---|---|---|
| `karla-400-700.woff2` | Karla | 400–700 (variable) |
| `sora-400-600.woff2` | Sora | 400–600 (variable) |
| `dmmono-400.woff2`, `dmmono-500.woff2` | DM Mono | 400, 500 |

All three are licensed under the SIL Open Font License 1.1:

- Karla — Jonathan Pinhorn
- Sora — Jonathan Barnbrook / Studio Barnbrook
- DM Mono — Colophon Foundry for Deepmind

Copies live in `ui/public/fonts/` for the frontend to serve.
